# AppJars Community

This repository exists to host **[AppJars Discussions](https://github.com/orgs/AppJars/discussions)**
— the public forum for everyone using AppJars. There is no code here.

## What Discussions are for

Open to everyone, free users included:

- *"Is X supported?"* · *"Are you planning Y?"*
- *"How do people usually approach Z with this AppJar?"*
- Ideas for new features, and for AppJars that do not exist yet
- Showing what you have built

Other users answer, and so do we when we can add something. If a discussion turns out to be a
reproducible defect or a concrete feature proposal, it becomes an issue.

## Where else to go

| I want to… | Go to |
|---|---|
| Report a bug in an AppJar, or request a feature | [AppJars/appjars → issues](https://github.com/AppJars/appjars/issues/new/choose) |
| Report a problem with a demo or a kickstart | The issue tracker of that repository |
| Get help with **my own** application | [Customer portal](https://customers.flowingcode.com) — included with Startup and Enterprise |
| Read the documentation | [docs.appjars.com](https://docs.appjars.com) |
| Report a security vulnerability | **security@appjars.com** — never in public. [Policy](https://www.appjars.com/security/) |

Full explanation of every channel: [SUPPORT.md](https://github.com/AppJars/appjars/blob/main/SUPPORT.md)
